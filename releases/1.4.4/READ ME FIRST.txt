TRADINGAGENTS FOR WINDOWS - READ ME FIRST
=========================================

WHAT THIS IS
TradingAgents is a free, open-source research tool (github.com/TauricResearch/TradingAgents).
A team of AI "analysts" (market, news, social sentiment, fundamentals) studies a stock,
a bull and a bear researcher debate it, a trader and a risk team weigh in, and a
"Portfolio Manager" gives the final call. The AI itself comes from a provider you choose
(Claude by Anthropic is recommended); you pay that provider per use.
It is a research tool only: it does NOT place trades and it is not financial advice.

STEP 1 - INSTALL (one time; usually 5-15 minutes, longer on a slow connection)
1. Double-click "TradingAgents-Setup.exe".
   Windows may show a blue "Windows protected your PC" (SmartScreen) box, because this
   program is not code-signed. That is expected. Click "More info", then "Run anyway".
   (Nothing needs an administrator password to start it.)
2. A window opens. Click "Get started", then on "Connect your AI":
   - Claude is pre-selected and recommended; click another card to use a different provider,
   - click "Get your key here" if you still need a key, then paste it into the key box
     (Ctrl+V or right-click > Paste; click "Show" if you want to see what you pasted),
   - optionally open "Advanced" to paste a free FRED key for US economic data (you can skip it),
   - click "Test key". The setup checks your key with the provider using a free call
     (no usage charged) and shows a green check or a clear message. You can click "Install"
     only after the key passes. For a few providers no free check exists; the setup says so
     and lets you continue.
3. The "Setting things up" screen shows a progress bar, a checklist and the live details.
   Leave it open; it moves on by itself when it is done. It will:
   - install Python 3.12 if you don't have it (Windows may ask for permission - click Yes)
   - download TradingAgents and everything it needs into %LOCALAPPDATA%\TradingAgents
     (a folder Windows keeps out of OneDrive). Some steps are quiet for a while; the
     live details show a "still installing (N min elapsed)" line every minute so you know it is alive.
   - save your key on this PC only, and put a "TradingAgents" icon on your Desktop
4. When you see "TradingAgents is ready", click "Open TradingAgents" to start it right away,
   or "Open the guide" / "Open reports folder". If setup stops, the screen says why in plain
   English; "Copy details" copies it so you can paste it to whoever set this up for you.

(If you received the ZIP version instead of the EXE: extract the ZIP, double-click
"1 - Install (double-click).bat", type the provider's number, paste the key when asked -
nothing shows while you paste, that is normal - and press any key when it says
INSTALL COMPLETE. Same result.)

CHANGING PROVIDER OR KEY LATER
Double-click "TradingAgents-Setup.exe" again and pick the provider and paste the key you want.
Nothing is reinstalled, only your provider and key are updated. (With the ZIP version: double-click
"1 - Install (double-click).bat" again; it offers "Change the AI provider or update API keys (quick)".)

STEP 2 - RUN IT (every day)
1. Open the "TradingAgents" icon on your Desktop (double-click it). A window opens.
2. Pick or type a ticker (e.g. AAPL, NVDA, SPY, BTC-USD), then click Analyze.
3. It analyzes the ticker as of today's date. The list on the right shows each analyst finishing
   as the agent team works; a full run usually takes several minutes. Leave the window open.
   (On weekends, holidays or before the market opens it uses the latest available prices.)

WHERE THE FINAL TRADING DECISION APPEARS
- In the same window, when the run ends: a big colour badge (BUY green, OVERWEIGHT light green,
  HOLD amber, UNDERWEIGHT orange, SELL red, REVIEW grey) with a one-line meaning, the key reasons
  under "Why", and a card for each analyst, the bull vs bear debate, the trader and the risk team
  (click a card to open it).
- "Open full report" opens the complete text report in Notepad. Every report is also saved in the
  "reports" folder inside %LOCALAPPDATA%\TradingAgents, named like  SPY_2026-09-28_0930.txt  (with a matching
  .json file the window reads). The top of the text report shows the FINAL DECISION and which AI
  provider and models produced it; below it is the Portfolio Manager's reasoning, then the full
  report from every agent.
- "Past reports" (top right) lists every earlier report; click one to open it again.
- Prefer the old black window? Double-click "Run TradingAgents (console).bat" in the folder
  %LOCALAPPDATA%\TradingAgents. It asks for a ticker, prints the decision between two ===== lines
  and opens the text report in Notepad.
The decision uses a 5-step scale:
  BUY          = buy / open a position
  OVERWEIGHT   = lean buy (hold more than a normal position)
  HOLD         = keep what you have, no change
  UNDERWEIGHT  = lean sell (trim, hold less than normal)
  SELL         = sell / exit
  REVIEW       = the AI gave no clear rating; read the Portfolio Manager section yourself

WHAT IT COSTS
TradingAgents is free. Each run uses the AI through YOUR account with the provider you
picked, billed per use. Every run makes at least a dozen AI requests, and more when analysts
fetch data, so the cost per run varies with the ticker and how much news/data there is.
After your first run, check the usage page in your provider's console to see the real cost,
and set a monthly spend limit there if the console offers one.

If you switch to DeepSeek (TradingAgents window > "AI settings"), the analysts use deepseek-flash and the
final decisions use deepseek-v4-pro. DeepSeek publishes its price per million tokens at
platform.deepseek.com; the real cost of a run is shown on your DeepSeek usage page after you run it.

WHERE REPORTS ARE SAVED (version 1.4.3 and later)
New reports are saved in the "reports" folder inside C:\Users\<you>\AppData\Local\TradingAgents
(use "Open reports folder" under Past reports). Reports from older versions stay in the
"TradingAgents Reports" folder on your Desktop and are still listed under Past reports.

UPDATES AND DIAGNOSTICS (two icons on your Desktop - both run ONLY when you double-click them)
- "TradingAgents - Check for updates": looks at a public web page for a newer, signed version.
  The update is signed by the person who set this up; your PC checks that signature and a
  fingerprint of every file before doing anything. It shows you what changed and asks you to type
  Y. Nothing is installed without your Y. A rollback copy of what you have is saved first, and your
  API key / .env file is never touched. To go back after an update, open the folder
  %LOCALAPPDATA%\TradingAgents and double-click "Undo last update.bat".
  Every check is written to %LOCALAPPDATA%\TradingAgents\update.log
- "TradingAgents - Send diagnostics": makes one zip file on your Desktop (versions, installed
  packages, the last lines of the logs, your settings with every value hidden). You can open it
  and read it. Nothing is sent anywhere - if you want help, YOU attach it to your Upwork message.
- Nobody can connect to your PC. There is no background program, no scheduled task, no remote
  access and no usage tracking. The only network request is your PC downloading the public update
  files when you click "Check for updates".

IF SOMETHING GOES WRONG
- The window shows a PROBLEM message in plain English, naming your provider and what to do
  (for example: key rejected, out of credit, rate limit, no internet).
- Install details: %LOCALAPPDATA%\TradingAgents\install-log.txt
  (paste %LOCALAPPDATA%\TradingAgents into the File Explorer address bar to open the folder)
- Last run details: %LOCALAPPDATA%\TradingAgents\last-run-log.txt and last-error-log.txt
  (send these to whoever set this up for you; they never contain your API keys)
- "already exists and looks like your own copy of the TradingAgents source code": the
  installer found a git checkout at %LOCALAPPDATA%\TradingAgents and left it alone. Rename or
  move that folder, then run the installer again.
- Your keys are stored only on this PC in %LOCALAPPDATA%\TradingAgents\.env - don't share
  that file.
- To uninstall: delete the folder %LOCALAPPDATA%\TradingAgents, the Desktop icon and (if it exists)
  the "TradingAgents Reports" folder on your Desktop. (Python stays installed; remove it from Windows Settings >
  Apps if you want.)
